# Mino

Social network platform with posts, comments, likes, stories, and real-time chat features.

## 🚀 Features

- 📝 **Posts and feed** - Create and share posts
- 💬 **Comments** - Comment on posts
- ❤️ **Likes** - Like and react to content
- 📱 **Responsive** - Mobile-first design
- 👤 **User profiles** - Profile management and avatars

## 🛠️ Tech Stack

- **Frontend**: PHP, JavaScript, HTML, CSS
- **Backend**: PHP
- **Database**: MySQL
- **Styling**: Custom CSS

## 📁 Project Structure

`
Mino/
├── index.php          # Main feed
├── post.php           # Post creation
├── like.php           # Like functionality
├── coment_post.php    # Comments
├── tchat.php          # Chat
├── css/               # Stylesheets
├── bd/                # Database
└── README.md
`

## 🚀 Installation

`ash
git clone https://github.com/Notho-freedom/Mino.git
cd Mino
`

Configure database connection in include.php.

## 🏃 Running

Deploy to a PHP-enabled web server (Apache/Nginx + PHP + MySQL).
